# MERN E-Commerce Web Application

## 📌 Project Overview

A full-stack **E-Commerce Web Application** built using the **MERN Stack**. The application provides a user-friendly interface for browsing products and managing items in a shopping cart.

## 🛠️ Technologies Used

* **MongoDB Atlas** – Cloud database for storing application data
* **Express.js** – Backend framework for creating APIs
* **React.js** – Frontend library for building the user interface
* **Node.js** – Runtime environment for the backend
* **Postman** – Used for testing and validating REST APIs
* **Render** – Used for deploying the application

## ✨ Features

* Product listing
* Add products to cart
* Remove products from cart
* Responsive user interface
* REST API integration
* Cloud database using MongoDB Atlas

## 🔧 Development Process

1. Created the frontend using **React.js**.
2. Developed the backend using **Node.js and Express.js**.
3. Connected the application with **MongoDB Atlas**.
4. Created and tested REST APIs using **Postman**.
5. Integrated the frontend and backend.
6. Tested the complete application.
7. Deployed the application on **Render**.

## 🗄️ Database

The application uses **MongoDB Atlas** as the cloud database for storing application data.

## 🚀 Deployment

The application was deployed using **Render**.

### Deployment Steps

1. Uploaded the project to GitHub.
2. Connected the GitHub repository with Render.
3. Configured the required environment variables.
4. Set up the build and start commands.
5. Deployed the application on Render.

## 🧪 API Testing

**Postman** was used to test and validate the backend REST APIs, including:

* GET requests
* POST requests
* PUT/UPDATE requests
* DELETE requests
